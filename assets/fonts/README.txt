Ablockalypse font files
=======================

Shipped:
  MartianMono-Regular.ttf   Default UI font (Latin + Cyrillic).
                            Used for en, es, fr, de, pt-BR, ru.

Optional CJK drop-ins (not shipped). Place these exact filenames here
so Japanese and Simplified Chinese can render:

  NotoSansCJKjp-Regular.otf  Japanese (ja)
  NotoSansCJKsc-Regular.otf  Simplified Chinese (zh-CN)

If either CJK file is missing, the game logs a warning and falls back
to MartianMono-Regular.ttf. It will not crash.
